# Emília Schmidtová – portfólio

Digitálny marketing & e-commerce. Osobné portfólio s nástrojmi pre sieť e-shopov LEDAKCIA:

- **Popisovač** – AI produktové popisy a SEO texty v 8 jazykoch (`tools/popisovac/`)
- **Bannerovač** – promo bannery pre 8 trhov a 4 formáty (`tools/bannerovac/`)
- **Svetelný poradca** – „Aké svetlo potrebujem?“ pre zákazníkov (`tools/poradca/`)

Statická stránka bez build kroku. Spustenie lokálne: `python3 -m http.server` v tomto priečinku.
